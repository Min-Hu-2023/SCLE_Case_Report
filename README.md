# SCLE_Case_Report

To reproduce the analysis and figures:
1. Download the data and all three scripts into the same directory
2. Run "SCLE_Preprocessing" to save the data into zarr files
3. Run "SCLE_Cell_Type_Annotation" to annotate cell types
4. Run "SCLE_Figs" to reproduce the analysis and figures
